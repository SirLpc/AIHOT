# UnityHot

An independent Chinese-language developer-news index for Unity international and Tuanjie Engine, based on the MIT-licensed AIHOT framework. It retains aggregation, server-rendered pages, reports, feeds, API and MCP access.

Product identity and exact release versions stay separate. Chinese text or a .cn domain does not identify Tuanjie. Source ownership is independent of product identity. The site publishes summaries and original links; full-text redistribution is disabled.

See [the Chinese README](README.md), [setup](docs/UNITYHOT_SETUP.md), [source provenance](docs/SOURCES.md) and [validation status](docs/DEVELOPMENT_STATUS.md).

This is a local adaptation, not a public deployment or an official Unity site. External collection, paid model calls and notifications default off. Operator identity, legal pages, calibration and production configuration still require approval.

Original UH branding is distinct from the upstream framework and Unity logos. [LICENSE](LICENSE) and [NOTICE](NOTICE) are preserved.
